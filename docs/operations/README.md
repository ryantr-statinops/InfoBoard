# Operations

This directory explains how InfoBoard is packaged, distributed, installed, updated, diagnosed, and uninstalled in a pure Manifest V3 environment.

---

## Operations Guides

1. [**Packaging and Installation**](packaging-and-installation.md): Building the extension bundle (`npm run build:extension`), loading as an unpacked developer extension, or packaging for the Chrome Web Store.
2. [**Updates, Rollback, and Repair**](updates-rollback-and-repair.md): Understanding the update lifecycle, rolling back releases, and automatic self-healing mechanisms.
3. [**Diagnostics, Reset, and Uninstall**](diagnostics-reset-and-uninstall.md): Inspecting extension logs, clearing session state, and cleanly removing the extension with zero leftover artifacts.
