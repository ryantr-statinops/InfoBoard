# Capture milestone acceptance

| Gate | Required evidence | Status |
| --- | --- | --- |
| Package completion | All required package tasks checked with execution records | pending |
| Contract behavior | Package contract and integration tests pass | pending |
| Data safety | Failure, retry, migration, or rollback evidence as applicable | pending |
| Quality | Ruff and relevant test suites pass | pending |
| Review | Rollups and traceability updated in the completion commit | pending |

No checkbox appears here because package task files are the authoritative completion records.
