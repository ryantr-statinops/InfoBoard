## Discipline

- Implement one vertical contract at a time and keep schema/API compatibility explicit.
- Do not mark work verified from target docs or mock-only behavior.
- Do not create empty per-task execution files; the full implementation rewrite defines evidence storage.
- Route out-of-scope needs through [the idea inbox](../../product/ideas.md).
