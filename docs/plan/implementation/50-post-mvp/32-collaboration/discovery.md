# Discovery — Identity, sharing, and collaboration

## Questions and prototype gate

Define ownership, authorization matrix, invitations, audit log, revoke lifecycle, stale permissions, accidental sharing, and recovery. Prototype invite/share/revoke on non-production data before deciding on APIs.

## Implementation-ready gate

Require stable sync/identity, explicit consent UX, authorization and audit model, revoke guarantees, abuse controls, export/delete behavior, and acceptance fixtures.
