# Discovery — Browser data portability

## Data-layer gate

Evaluate bookmarks/URLs/titles/history references/page snapshots first. Treat credentials, payment data, security keys, cookies, tokens, localStorage, IndexedDB, Cache Storage, and Service Worker data as separate high-risk layers.

## Required evidence

Choose browser/platform matrix, read-only prototype on profile copies, per-class consent, encrypted handling, per-origin rules, compatibility fixtures, failure/rollback behavior, and backup/restore verification. Never bypass browser encryption or security controls.
