# Discovery — AI and providers

## Questions and experiments

Choose one user outcome, establish a non-AI baseline, define citation/provenance, provider/privacy matrix, cost limits, model drift handling, data minimization, and prompt-injection controls. Compare local and cloud provider prototypes.

## Implementation-ready gate

Require evaluation metrics, citations, explicit consent, cost budget, failure fallback, provider contract, and an explicit write-back policy. Original content must remain authoritative.
