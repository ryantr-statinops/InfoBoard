# Design & User Experience

This directory details the user experience, keyboard ergonomics, interaction states, and scoring behavior for the InfoBoard extension.

---

## Design Documents

1. [**Product Surface**](product-surface.md): Popup layout, quick-toggle ergonomics (`Alt+W` -> `Enter`), keybindings, and ARIA accessibility.
2. [**Interaction States**](interaction-states.md): State transitions from launch to filtering, tab switching, and dismissal.
3. [**Search Behavior & Scoring**](search-behavior.md): Multi-tier lexical scoring algorithm (Exact prefix, word boundary, acronym, and MRU decay boost).
