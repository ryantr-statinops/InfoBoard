# Mockups

Mockups are optional visual references. They do not define product behavior, platform support, permissions, or implementation details.

The approved visual and interaction behavior is documented in:

- [Product surface](../product-surface.md)
- [Interaction states](../interaction-states.md)
- [Canonical user experience contract](../../plan/refactor/user-experience.md)

A future mockup must be reviewed against those contracts and must not introduce a capability that is absent from the product specification.
