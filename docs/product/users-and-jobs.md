# Users and jobs

## Primary user

The MVP serves one person using InfoBoard on their own computer to save and revisit web content for work, learning, or personal projects. They should not need to understand databases, embeddings, or indexing to complete the core loop.

## Primary jobs

- Save a useful public web page quickly.
- Retain enough content to recognize and read it when the source changes or disappears.
- Record why the page matters.
- Group bookmarks by project or topic without forcing a single hierarchy.
- Find a bookmark by exact words, remembered meaning, source, collection, tag, or date.
- Understand capture and indexing failures and retry them safely.
- Back up, restore, and rebuild the application without losing canonical data.

## Experience expectations

- A simple default path covers capture, organization, browsing, and search.
- Technical configuration and maintenance remain in clearly labeled settings.
- Provider setup explains what data leaves the computer before consent is recorded.
- Failure messages describe the affected capability and the next safe action.

## Environment

- Single local installation and single user.
- Local browser-based UI, responsive at desktop and mobile-sized viewports.
- Public URLs only for MVP capture.
- English product interface is the reference contract; localization is a later decision.
