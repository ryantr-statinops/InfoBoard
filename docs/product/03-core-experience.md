# InfoBoard — Core experience

## Experience loop

```text
Capture → Understand source → Organize → Retrieve → Export/Move
```

## Core flows

- Save text, URL hoặc file.
- Import bookmark và nhận diện source/provenance.
- Lưu page snapshot để đọc offline.
- Gán collection, note và trạng thái.
- Tìm theo keyword hoặc ngữ nghĩa, rồi mở lại item liên quan.
- Export nội dung và metadata để chuyển browser hoặc thiết bị.
- Mở migration assistant để xem trước từng loại dữ liệu trước khi import/export.

## Hai chế độ trải nghiệm

### Simple mode

One-click import, default an toàn, ít lựa chọn, preview dễ hiểu và thông báo rõ dữ liệu nào không thể chuyển.

### Advanced mode

Chọn browser/profile/source, preview theo loại dữ liệu, mapping collection, conflict handling, export format, logs và CLI integration.

## Future capability interfaces

Ở cấp product, các capability tương lai cần có các khái niệm: source adapter, import preview, export package, migration report (`imported`, `skipped`, `conflicted`, `failed`) và consent boundary. Chúng chưa phải API/schema production.
