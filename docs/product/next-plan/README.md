## Discovery gate chung

Một capability chỉ được chuyển vào implementation planning khi đã có:

1. Outcome và user value đo được.
2. Primary user và workflow mục tiêu.
3. Data classes, consent và privacy boundary.
4. Feasibility evidence hoặc prototype.
5. Threat model và compatibility constraints khi có dữ liệu nhạy cảm.
6. Failure behavior, fallback và recovery path.
7. Acceptance criteria, migration impact và rollback strategy.
8. Product decision được ghi nhận và owner chấp thuận.

Việc một capability xuất hiện trong Next Plan không đồng nghĩa InfoBoard đã cam kết thời điểm phát hành hoặc hỗ trợ mọi browser/platform.
